# Overview

This repository implements a POC for a job interview assignment that consists of
Designing and Building a Data Analysis Chat Assistant

# Task Context
I have provided as a pdf document a copy of the assignment so as to provide you with a ground truth context for your tasks

# Tasks Overview

1. Read all the files in the repository carefully and familiarize yourself with all the code and documentation in the repository.

2. Write a one-page summary in markdown formnatof what the code in this file does and place it in a file called poc-summary.md in the docs subdirectory.

3. Create a diagram of the architecture and data flow in this POC. It should naturally be well alligned with the LangGraph graph, but include external entities such as the BQ tables and the Gemini LLM. Also include validation and security checks even if they are not explicfit nodes in the LangGraph graph. Place the diagram in the diagrams subdirectory as both a .jpg and a mermaid format file called poc-architecture.jpg (or png) and poc-architecture.svg

4. Create a concise and precise markdown file in the docs directory called 
poc-issues.md that contains any issues, errors or suggestions you may have after you have read through the repository. Keep it brief and simple and fairly high level when possible.

# Task Details

1. Use different colors for the background of the boxes. Use the same color for all the LangGraph graph nodes, and then other colors for other entities based on their type. Provide a legend documenting the color codes.

2. Provide intuitive labels on the boxes and the edges as much as possible while trying to keep the diagram readable, clean and elegant.
